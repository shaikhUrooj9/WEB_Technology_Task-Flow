# 📌 Task Flow (Section A)

A simple **Task Management Web Application** built for **CS4717 - Web Technologies I (Phase 1 Assignment)**.
This project demonstrates basic UI design and JavaScript interactivity.

---

## 🚀 Features

* 📋 Display task list (with placeholder tasks)
* ➕ Add new tasks dynamically
* ❌ Delete tasks instantly
* ⚠️ Form validation (prevents empty input)
* 📅 Automatic date display for tasks
* 🔓 Logout button with redirection

---

## 🛠️ Technologies Used

* **HTML5** → Structure of the application
* **CSS3** → Styling and layout (Flexbox used)
* **JavaScript (Vanilla JS)** → Interactivity and DOM manipulation

---

## 📂 Project Structure

```
Task-Flow/
│── index.html      # Main HTML file
│── style1.css      # Styling file
│── script.js       # JavaScript functionality
│── login.html      # Login page (for logout redirect)
```

---

## 🎯 How It Works

1. User enters task details (Title, Category, Content)
2. Clicks **Create Task**
3. Task is added to the list dynamically
